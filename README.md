# 🚗 Santa Lúcia Solidária

**Sistema web de caronas solidárias para a comunidade da Paróquia Santa Lúcia.**

## 📌 Sobre o projeto

O Santa Lúcia Solidária é um projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas da Universidade Cruzeiro do Sul. A proposta é facilitar a conexão entre moradores do Conjunto Santa Lúcia, no bairro Jabotiana, em Aracaju/SE, que oferecem ou necessitam de transporte para participar de missas e atividades comunitárias.

A iniciativa busca incentivar a colaboração, a integração entre os moradores e a mobilidade comunitária.

## 🎯 Objetivo

Desenvolver uma plataforma simples e acessível que permita organizar ofertas e solicitações de caronas gratuitas entre os membros da comunidade.

## ⚙️ Funcionalidades previstas

- Cadastro e autenticação de usuários;
- Cadastro de ofertas de caronas;
- Consulta de caronas disponíveis;
- Solicitação de vagas;
- Confirmação ou rejeição de solicitações pelo motorista.

## 🛠️ Tecnologias planejadas

- **Java 21**
- **Spring Boot 3**
- **Thymeleaf**
- **Bootstrap 5.3**
- **Spring Data JPA**
- **PostgreSQL**
- **Git e GitHub**

## 🏗️ Arquitetura

O projeto utilizará arquitetura monolítica em camadas, separando apresentação, regras de negócio e persistência de dados.

## 🌱 Objetivo de desenvolvimento sustentável

O projeto está relacionado ao **ODS 11 — Cidades e Comunidades Sustentáveis**, especialmente à Meta 11.2, considerando sua contribuição local para ampliar as possibilidades de acesso ao transporte.

## 📚 Contexto acadêmico

Projeto desenvolvido no âmbito da disciplina Projeto de Software do curso de Análise e Desenvolvimento de Sistemas da Universidade Cruzeiro do Sul.

## 🚧 Status do projeto

Em desenvolvimento — construção do MVP.
